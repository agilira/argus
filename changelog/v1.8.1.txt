FIXED
-----

1. Every audit record said process_name "argus".

   getProcessName returned a constant, so an audit trail shared by several
   programs, or read after the fact, could not say which application wrote
   a record: the library's name stood in for the application's. It is now
   the running program's name as it was started (the base of os.Args[0],
   without .exe), "argus" only when there is none.

2. TestRemoteConfigManager_AuditEventAndComponent failed when run alone.

   It used the fake:// remote provider without registering it, relying on
   another test having done so first. It registers it itself, as its
   neighbours do.
